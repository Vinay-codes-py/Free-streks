# Ethical Learning Toolkit

This project is a multi-feature educational dashboard built with Streamlit.

## Included tools
- Calculator
- Length / weight / temperature converters
- BMI calculator
- Countdown timer
- Study notes
- Image upload and resize preview
- Animated battery status browser demo

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Purpose
This app is intended for ethical, transparent educational use, demonstrating browser and utility features in a safe way.
